==================================================
A. AIR STRIKE — MANUAL CHECKS
==================================================
[ ] Warning indicator appears clearly before the first shell.
[ ] Warning countdown/status is readable in the HUD.
[ ] Exactly seven shell visuals appear.
[ ] Shell stagger/order looks intentional and smooth.
[ ] Camera frames the strike zone correctly.
[ ] Camera does not snap/jitter badly during the barrage.
[ ] Visual shell positions match the actual damage/crater locations.
[ ] Expected craters appear at shell impacts.
[ ] Self-damage visibly updates HP correctly.
[ ] Friendly fire visibly works in Team mode.
[ ] Shield interaction looks correct and Shield is consumed as intended.
[ ] Pickup hit by Air Strike disappears and enters inventory correctly.
[ ] Pickup collection via Air Strike preserves the shooter's turn as intended.
[ ] Air Strike without pickup advances the turn once and only once.
[ ] Match-ending Air Strike resolves cleanly.
[ ] Player standing over terrain destroyed into a void falls/animates correctly.
[ ] IMPORTANT EDGE CASE: if one Air Strike shell starts a player's fall and later shells modify nearby terrain before the fall finishes, verify the fall animation does not restart, snap, teleport or otherwise look wrong.

NOTE:
The last item is NOT currently a confirmed bug. It is a manual visual/temporal check that cannot be certified from static code review alone.
