NEW FINDINGS FROM COBY DEBUG V2
==================================================
CONFIRMED ISSUE A — Air Strike void death presentation
- Air Strike terrain deformation can cause immediate death with motion=null.
- This can skip the normal falling animation used by base projectile void deaths.
- Priority: fix before or at start of Phase 6D.

CONFIRMED ISSUE B — Initial player randomization is weighted
- chooseInitialPlayerId() does not give all players equal starting probability.
- Unless deliberate, this is a fairness bug/undesired rule.
- Decision recommended: make starter selection uniform.

POTENTIAL VISUAL RISK
- settleAfterAirStrike() can run after each shell.
- Multiple shells may overwrite/restart a player's fall motion.
- Must be manually tested and then fixed if visible.

TECHNICAL DEBT
- terrain/base surface formulas exist in multiple server/client files.
- Current values appear aligned but future drift risk is high.

MOBILE STATUS
