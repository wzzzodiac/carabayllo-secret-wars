5. COMMON DEBUG CHECKLIST
==================================================
A. Feature appears on server but not browser
Check:
1. server public state exposes it,
2. Socket.IO room_state contains it,
3. client copies/keeps the field,
4. renderer/UI reads correct field,
5. HTML module/cache query versions were updated if necessary,
6. browser is not serving stale GitHub Pages assets.

B. Special weapon does base damage AND special damage
Check special projectile resolution paths.
Past bug class:
- base-resolution leakage after Triple/Cluster/special mechanics.
Look for guards/neutralization around special weapon resolution.

C. Turn ends too early/too late
Inspect:
- match.turnEndsAt
- projectile.resolveAt
- specialResolveAt
- resumeTurnMs
- pendingResult
- advanceTurnIfDue* functions
- whether utility should consume turn

D. Utility unexpectedly ends turn
Current intended behavior:
- Shield: does not consume offensive turn.
- Heal: does not consume offensive turn.
Verify Air Strike and offensive special weapons follow their intended resolution path.

E. AFK skip misbehaves
Inspect:
- afk-vote.js
- eligible voters
- active player activity registration
- cancellation on input
- disconnect changes
- majority threshold

F. Pickup missing / wrong item
Inspect:
- pickup spawn cadence
- pickup lifetime
- max pickups
- item pool weights
- phase6c reroll/extension logic
- inventory capacity
- touch vs explosion collection

G. Player dies after terrain deformation incorrectly
Inspect:
- surface calculation
- post-explosion settle/fall logic
- holes for current terrain preset
- motion/fall timing
- pending match result

H. Different browser shows stale UI
Likely cache problem.
Past project history includes explicit cache-busting commits.
Inspect index.html module/script URLs and GitHub Pages cache behavior before rewriting correct gameplay code.
