PHASE 6F — IMPLEMENTED PRESENTATION
==================================================
New frontend wrapper: renderer6f.js
- wraps renderer6d.js instead of replacing hardened gameplay rendering
- uses exact inherited camera snapshot
- adds LIVE SPECTATOR FEED when another player owns the turn
- spectator feed shows active player, selected weapon, angle, power and wind
- adds colored active-weapon badge above the current player
- adds weapon-specific top resolution ribbon while an attack resolves
- resolution labels cover Basic, Heavy, Triple, Cluster, Air Strike and Nuke phases
- replaces the inherited Phase 6E countdown identity visually with Phase 6F identity
- does not modify projectile simulation, damage, terrain, turn timing or authoritative state

New frontend wrapper: combat-controls6f.js
- wraps combat-controls6d.js
- spectator state includes active player + weapon + angle + power
- own-turn state includes currently selected weapon
- adds WEAPON cell to battle info
- adds AIM SYNC cell showing LIVE during started matches
- keeps Phase 6D/6E movement and Nuke HUD behavior underneath

Renderer camera API bridge:
- renderer6d.js now exposes getViewSnapshot() from its exact base renderer camera
- 6F uses that view rather than approximating camera geometry
