V0.9.6 CHANGES

PICKUP TOUCH
- Pickup collection now triggers when the current vehicle hitbox only grazes the visible pickup body.
- Vehicle hit radius remains 51 world units.
- Pickup visual allowance is 22 world units plus 1 unit tolerance.
- Effective pickup center-to-center touch threshold: 74 world units (previous custom threshold: 64).
- One pickup per player turn, two special inventory slots, touch-only collection and explosion-disabled collection remain unchanged.

TRAVERSAL
- Normal jump distance remains 180 world units.
- Existing adaptive ledge vault remains available only when a normal jump is truncated by unusually tall/wide terrain; adaptive landing remains capped at 420 world units and 1050 apex.
- New natural ledge drop: walking toward a solid surface that is lower by more than the normal 42-unit walk threshold now creates a short authoritative fall instead of requiring a forward jump.
- Natural ledge drop does not convert upward walls or void into fake landings.

MUSIC
- Lobby/countdown/post-match: Sports Opener.
- Turns 1–8: Dark.
- Turn 9: long fade to silence.
- Turn 10+: Adrenaline.
- Loop fade state is protected from normal room-state refreshes.
- Track end has an explicit restart/fade-in fallback.
- Track changes keep independent outgoing/incoming crossfades.
- Music volume remains locally adjustable 0–100 and persisted.

WEAPON / UTILITY SFX
- SFX playback now uses preloaded voice pools so multi-projectile weapons can overlap without cutting each other off.
- Normal network delay no longer silently drops launch/impact cues: authoritative events up to 2.5 seconds late are played immediately.
- Triple launch cues are slightly staggered to make the three shots audible.
- Air Strike shell cue uses visualStartAt; explosion uses impactAt.
- Nuke warning starts at target lock and stops at beam start; Nuke activation/explosion follows at beam start.
- Existing Basic / Heavy / Triple / Cluster / Air Strike / Nuke / Shield / Heal mapping is retained.

MATCH START PRESENTATION
- Public countdown overlay is intentionally minimal.
- Visible content: START + map + mode.
- No version, internal phase, or arsenal-development text in the match-start overlay.
