CURRENT RELEASE
Orbital Artillery v0.9 Beta remains the public release identity.
Phase 9 remains CLOSED.
This snapshot records a post-Phase-9 v0.9 Beta balance/readability hotfix; it does not start Phase 10.

HOTFIX — VEHICLE SCALE
- Placeholder vehicle presentation reduced to 65% of the previous v0.9 size.
- Wheels, cannon, Shield ring and vehicle-attached text/badge scale with the vehicle.
- Global spectator/HUD panels are intentionally not reduced.
- Projectile vehicle hit radius reduced from 78 to 51 world units to match the smaller visual footprint.

HOTFIX — COMBAT BALANCE
HP cap remains 100.
- Basic: maximum direct damage 10.
- Heavy Bomb: maximum direct damage 20.
- Triple Shot: 3 projectiles; each projectile deals 10 only when that individual projectile directly hits a vehicle. Misses/terrain-only child impacts do not deal that 10 to the vehicle.
- Cluster Bomb: existing 14 max damage per subimpact retained because no new value was requested.
- Air Strike: 7 shells; each shell deals 5 only when that shell directly reaches the vehicle hitbox.
- Nuke Laser: direct damage remains 20.
- Heal: +20, capped at 100 HP.
- Shield: existing 50% mitigation retained, but it now protects against one complete incoming attack sequence and is consumed if that attack actually hits. This prevents Triple/Air/Cluster from consuming the Shield on only the first child impact.

NUKE TERRAIN
- Existing diagonal scar geometry remains.
- Direct damage remains 20.
- Current safe diagonal scar depth increased slightly from 299 to 330.
- Radius/step/margin behavior remains unchanged.
- Scar remains below the vertical-void threshold used by the current regression contract.

CI FINDING AND FIX
The first Air Strike regression exposed one confirmed implementation bug: direct-hit detection used the vehicle position after crater settling, allowing a shell that had actually reached the tank to be treated as a miss after the terrain moved it slightly.
Fixed by evaluating Air Strike direct hits against the authoritative pre-attack position snapshot.
