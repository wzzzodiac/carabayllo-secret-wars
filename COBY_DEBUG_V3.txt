7. DEBUG CHECKLIST BY SYMPTOM
==================================================
Feature works on server but not browser:
1. public state contains field
2. room_state emits field
3. client preserves field
4. UI/renderer reads correct field
5. module/cache version current
6. deployed Pages actually updated

Turn stuck/double advances:
Inspect turnEndsAt, projectile resolveAt/specialResolveAt, pendingResult, shotResolvedAt, pickup-retain flow and AFK skip path.

Visual/server disagreement:
Check authoritative state first. Do not fix gameplay outcome only in renderer.

Special damage duplicated:
Check base-resolution leakage and whether special resolver neutralizes/owns base projectile resolution.

Pickup incorrect:
Check spawn cadence, lifetime, max count, pool weight, inventory space and movement-vs-explosion collection.

Disconnect issue:
Check old/new turnOrder, turnIndex, activePlayerId, resultFor and camera target.
