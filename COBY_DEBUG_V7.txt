2. CONFIRMED FINDINGS FIXED
==================================================
A1 — INVALID SPECTATOR TRAVERSAL MUTATED SHARED STATE
Root cause:
- Phase 6D compatibility wrapper expanded movementRadius/jumpsRemaining before inherited validation.
- rejected non-active movement/jump could leave traversal bookkeeping changed.
Fix:
- snapshot/restore traversal state on failed actions.
- expose free traversal only after successful action.
- public state hides obsolete Phase 4 radius/quota bookkeeping.
Regression:
- non-active move/jump rejects with not_your_turn and leaves shared state/player position unchanged.

A2 — NUKE OVERLAY CAMERA COULD DIVERGE FROM BASE WORLD
Root cause:
- renderer6d used an independently approximated fixed 1000x1000 camera view.
- renderer.js owns actual zoom, drag, transitions and projectile follow.
Fix:
- renderer.js exposes getViewSnapshot().
- renderer6d uses the exact base current view for every Nuke world-to-screen transform.
Result:
- source-level camera transform divergence removed.
- visual quality/alignment still requires manual browser observation.

A3 — NUKE BEAM GEOMETRY DID NOT MATCH TERRAIN-CUT CONCEPT
Root cause:
- beam used about 2100 vertical units over 1800 horizontal units, reading near-vertical while the gameplay effect removed a broad terrain support band.
Fix:
- vertical half-span reduced to 320.
- horizontal half-length remains 900.
- diagonal beam now crosses the broad destruction band coherently.
Regression checks major horizontal coverage and bounded vertical spread.

A4 — FREE NORMAL-JUMP SHORTENING ALSO SHORTENED VOID JUMPS
Root cause:
- inherited void death jump uses motion.type='jump'.
- Phase 6D shortened all jump motions to 500 ms.
Fix:
- shorten only jumps whose toY remains inside WORLD_HEIGHT.
- jump into void retains long core fall/death timing.
Regression added using Terraces central gap.

A5 — PHASE 6D FRONTEND IDENTITY INCONSISTENCIES
Fixed:
- Nuke now has native base-renderer item style instead of Heavy fallback.
- Nuke designator preview uses Nuke color.
- Nuke designator impact no longer renders fake Basic explosion.
- countdown stale PHASE 6C.2 text changed to PHASE 6D + Nuke Laser.
- frontend renderer chain cache-busted to worldender-3.
