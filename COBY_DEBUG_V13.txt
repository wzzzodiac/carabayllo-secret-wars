CONFIRMED FINDINGS FIXED

A1 — PHASE 7A MATCH-STATS MODULE COULD BE STALE AFTER FRONTEND UPDATE
Root cause:
- match-stats7a1.js changed after its initial phase7a1-stats-1 URL was introduced.
- client.js still requested the original cache key, so a browser could reuse the earlier panel and miss the latest match-summary fields such as most-used weapon.
Fix:
- index import map now maps phase7a1-stats-1 to phase7a1-stats-2.
- client entry cache advanced to phase7a1-stats-rematch-2.
Verification:
- Frontend CI on e97dbdacdbeb20e2b4938e35118f4d4a599018c1: SUCCESS.
- GitHub Pages on the same head: SUCCESS.

A2 — REAL PROJECTILE DAMAGE COULD BE LOST FROM STATS WHEN THE SAME RESOLUTION ALSO CAUSED A VOID DEATH
Root cause:
- the telemetry layer intentionally ignored HP->0 caused by void/environment so environmental death would not be counted as artificial damage.
- if an actual impact first dealt damage and its knockback/terrain collapse also sent the target into void during the same server resolution, the final state was voided and the real impact damage was also discarded.
Fix:
- telemetry snapshots now include lastDamage timestamp, amount and source.
- when a target is voided, only a fresh matching lastDamage amount is credited; the remaining HP loss caused by the environmental death is not counted as damage.
- regression test covers damage + void in one resolution.
Verification:
- latest Server CI including the regression suite: SUCCESS.

VERIFIED FROM SOURCE / TESTS
- authoritative gameplay remains inherited from Phase 6E/6D; Phase 7A.1 observes server outcomes rather than replacing combat physics.
- public state exposes matchStats, eventFeed, deathAttribution, matchSummary and rematchRules.
- stats include damage dealt/received, kills, assists, deaths, self-KOs, void deaths, pickups, biggest hit, shots/uses and per-weapon usage.
- self-damage cannot inflate the damage leaderboard.
- void deaths do not convert all remaining HP into fake damage.
- damage + void preserves only the actual lastDamage amount.
- kills are credited to the current non-self source when applicable.
- assist rule: every other prior non-self contributor to the victim in the current match gets one assist on that death.
- event feed is server-generated and capped at 36 events.
- successful weapon/utility use increments weapon usage; failed actions do not.
- finished match summary exposes duration, turns, result, top damage, top kills and most-used weapon.
- RANDOM terrain is host/lobby-only, resolves to a concrete map and clears READY states.
- rematch is host-only and finished-only.
- rematch preserves room code, players, mode and teams.
- same-map rematch preserves terrain; random rematch intentionally chooses another concrete terrain.
- rematch resets HP/alive state, arena, pickups, inventories, selection, Shield and telemetry, then starts one new countdown.
- match stats frontend is a DOM panel and does not modify renderer/camera authority.
- frontend CI checks match-stats7a1.js.
