2. COBY_GITHUB_DEBUGGING ACTION
==================================================
When Walter asks for a Coby Debug:
1. Read latest commits in BOTH repos.
2. Read highest progress/debug/TODO versions.
3. Inspect current source for mechanics, turn flow, multiplayer, UI, renderer, state boundaries and historical regression classes.
4. Inspect latest CI/workflow results.
5. Check frontend/backend deployment assumptions if relevant.
6. Separate findings into:
   A) CONFIRMED CODE BUG — source/reproduction proves it.
   B) MANUAL CHECK — requires actually seeing/playing.
   C) DESIGN DECISION — intentional; do not fix.
   D) TECH DEBT — maintainability, not current bug.
7. Fix confirmed code bugs directly only when requested/appropriate.
8. Re-check CI after code changes.
9. Re-review connected systems after fixes.
10. Add all unprovable visual/temporal/game-feel items to a NEW TODO version.
11. Never mark manual QA complete without Walter testing it on PC.
12. Phase gate result must state BOTH automated and manual status.

Result labels:
